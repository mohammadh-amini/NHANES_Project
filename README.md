## Overview
This project investigates the association between total sugar intake, smoking status, and tooth decay in US adults using data from the NHANES 2021-2023 survey. The project is structured in five phases, covering descriptive statistics, probability, statistical inference, regression, and sensitivity analysis.

## Research Question
Is sugar intake and smoking associated with tooth decay in US adults, even after controlling for age and gender?

## Tools and Libraries
- Python 3.15

- LaTeX (XeLaTeX) for report generation

## How to Run
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run `src/read_data.py` to load and clean data.
4. Run `src/descriptive.py` to generate statistics and plots.
5. Compile `reports/phase1/report.tex` with XeLaTeX.
